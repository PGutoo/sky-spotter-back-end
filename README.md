## 🇧🇷 Português

### Sobre o Projeto
A **Sky Spotter API** é o motor de telemetria astrométrica e integração científica do projeto **Sky Spotter** (NASA Space Apps Challenge). Desenvolvida em **Python (FastAPI)**, a API conecta o observatório web aos arquivos astronômicos da NASA (**NASA/IPAC IRSA** via protocolo **IVOA SIA v2**), atua como proxy de alta velocidade para recortes celestes (**IVOA HiPS2FITS**) e persiste as anomalias catalogadas pela comunidade no **Supabase**.

### Arquitetura e Funcionalidades
* **Consulta NASA IRSA (`IVOA SIA v2`):** Valida metadados espaciais (`POS=CIRCLE`) junto ao arquivo infravermelho da NASA (`irsa.ipac.caltech.edu/SIA`, coleção `wise_allwise_p3am_cdd`), preparando o pipeline para levantamentos multi-época como o **SPHEREx**.
* **Proxy de Imagens Astronômicas (`/api/sky-cutout`):** Contorna bloqueios de CORS e *hotlink* dos servidores acadêmicos externos, entregando projeções tangenciais (`TAN`) de $500 \times 500$ pixels ($0,25^\circ$ FOV) do levantamento **DSS2** (bandas vermelha e azul), além de contar com um gerador determinístico de campo estelar em SVG como contingência.
* **Persistência em Nuvem (Supabase):** Grava coordenadas celestes (`RA`, `Dec`), vetores de posição `(X, Y)` e classificações na tabela `anomalies`.
* **Motor de Recomendações Científicas:** Analisa os registros consolidados e sugere próximos passos automatizados (como cruzamento de órbitas com o *Minor Planet Center*).

### Endpoints Principais

| Método | Rota | Descrição |
| :--- | :--- | :--- |
| `GET` | `/` | Healthcheck da API e status de conexão com IRSA e Supabase |
| `GET` | `/api/nasa-pair` | Sorteia um alvo celeste, consulta o protocolo SIA v2 e retorna os links das Épocas A e B |
| `GET` | `/api/sky-cutout` | Proxy que baixa e entrega o recorte astronômico (`ra`, `dec`, `epoch`) com cache HTTP |
| `POST` | `/api/annotations` | Salva as marcações e classificações enviadas pelo observatório na tabela `anomalies` |
| `GET` | `/api/insights` | Retorna estatísticas globais, itens agrupados por painel e sugestões científicas de IA |

### Tecnologias Utilizadas
* **Python 3.10+** & **FastAPI**
* **Uvicorn** (Servidor ASGI)
* **HTTPX** (Requisições assíncronas aos servidores astronômicos)
* **Supabase Python Client (`supabase==2.9.0`)** & **Pydantic**

### Como Rodar Localmente

#### 1. Clone o repositório e crie o ambiente virtual
```bash
git clone [https://github.com/PGutoo/sky-spotter-api.git](https://github.com/PGutoo/sky-spotter-api.git)
cd sky-spotter-api

python -m venv venv
# Linux / macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate
```

#### 2. Instale as dependências
```bash
pip install -r requirements.txt
```

#### 3. Configure o Banco de Dados (Supabase)
No **SQL Editor** do seu projeto Supabase, execute o script abaixo para criar a tabela `anomalies`:
```sql
CREATE TABLE public.anomalies (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  image_id TEXT NOT NULL,
  ra TEXT NOT NULL,
  dec TEXT NOT NULL,
  x DOUBLE PRECISION NOT NULL,
  y DOUBLE PRECISION NOT NULL,
  category TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

ALTER TABLE public.anomalies DISABLE ROW LEVEL SECURITY;
NOTIFY pgrst, 'reload schema';
```

#### 4. Configure as Variáveis de Ambiente
Crie um arquivo `.env` na raiz do projeto com as credenciais do Supabase (**importante:** utilize a chave **Legacy `anon` public** em formato JWT iniciada por `eyJ...`):
```env
SUPABASE_URL=[https://seu-projeto.supabase.co](https://seu-projeto.supabase.co)
SUPABASE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

#### 5. Inicie o Servidor
```bash
uvicorn main:app --reload --port 8000
```
A API estará disponível em **`http://127.0.0.1:8000`** e a documentação interativa (Swagger UI) em **`http://127.0.0.1:8000/docs`**.

## 🇺🇸 English

### About the Project
**Sky Spotter API** is the astrometric telemetry and scientific integration engine powering **Sky Spotter** (NASA Space Apps Challenge). Built with **Python (FastAPI)**, it connects the web observatory to NASA astronomical archives (**NASA/IPAC IRSA** via the **IVOA SIA v2** protocol), acts as a high-speed image proxy for sky cutouts (**IVOA HiPS2FITS**), and persists community-annotated anomalies in **Supabase**.

### Architecture & Features
* **NASA IRSA Querying (`IVOA SIA v2`):** Validates spatial metadata (`POS=CIRCLE`) against NASA's infrared archive (`irsa.ipac.caltech.edu/SIA`, `wise_allwise_p3am_cdd` collection), aligning the data pipeline with multi-epoch surveys such as **SPHEREx**.
* **Astronomical Image Proxy (`/api/sky-cutout`):** Bypasses browser CORS and hotlink restrictions from external academic servers, serving $500 \times 500$ px tangential (`TAN`) projections ($0.25^\circ$ FOV) from the **DSS2** survey (red and blue bands), backed by a deterministic SVG starfield fallback generator.
* **Cloud Persistence (Supabase):** Stores celestial coordinates (`RA`, `Dec`), screen vectors `(X, Y)`, and classifications in the `anomalies` table.
* **Scientific Recommendation Engine:** Aggregates community records and generates automated follow-up guidelines (such as cross-referencing trajectories with the *Minor Planet Center*).

### Core Endpoints

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/` | API healthcheck and IRSA / Supabase connection status |
| `GET` | `/api/nasa-pair` | Selects a celestial target, queries SIA v2, and returns Epoch A & B image URLs |
| `GET` | `/api/sky-cutout` | Proxies and caches astronomical sky cutouts (`ra`, `dec`, `epoch`) |
| `POST` | `/api/annotations` | Persists user-submitted anomaly markers into the `anomalies` table |
| `GET` | `/api/insights` | Returns global discovery metrics, categorized panels, and AI recommendations |

### Tech Stack
* **Python 3.10+** & **FastAPI**
* **Uvicorn** (ASGI server)
* **HTTPX** (Async HTTP client for astronomical services)
* **Supabase Python Client (`supabase==2.9.0`)** & **Pydantic**
